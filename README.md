# Dots & Lines

React Native Expo mobile game with offline pass-and-play and online Socket.IO multiplayer.

## Start

Mobile: `cd mobile && npm install && npx expo start`

Server: `cd server && npm install && npm start`

Online mode requires setting the API URL in mobile/App.js to a deployed WebSocket-capable server. Offline mode needs no network.

Source starter archive is also available in the ChatGPT conversation. Android APK is not yet built.
